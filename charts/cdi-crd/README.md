## Installing

Before you can install, you need to add the `kubevirt` repo to [Helm](https://helm.sh)

```shell
helm repo add kubevirt https://kubevirt.github.io/charts
helm repo update
```

**This chart must be installed before installing the [cdi chart](../cdi)**

Now you can install the chart:

```shell
helm upgrade cdi-crd kubevirt/cdi-crd --install -n cdi --create-namespace
```
